<h1 align="center">
XENGINE
</h1>

**XENGINE** (pronounced _zen-jin_), or **XEN**, is a DirectX 12-powered 3D game engine for Windows written in C++. Its
architecture in heavily inspired by Unreal Engine and includes a fully-featured editor and suite of tools for developing
games on Windows.

> [!NOTE]
> This is **NOT** a production-ready engine (the code will make that obvious). This is a proof-of-concept developed for
my own amusement, and is the culmination of over 6 years of work.
