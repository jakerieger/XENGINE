<h1 align="center">
XENGINE
</h1>

**XEN**GINE (X-Engine), or XEN is a 3D game engine for Windows written in C++ and utilizing DirectX 12.

> [!NOTE]
> This is **NOT** a production-ready engine. This is a proof-of-concept developed for my own amusement.
